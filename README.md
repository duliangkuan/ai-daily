# 研究Agent的云 · AI 日报

> 每天扫描 65 个全球 AI 信源、1400+ 条资讯，AI 精选出最值得读的约 160 条，早晚两次直达你的邮箱。

这是「研究Agent的云」AI 日报订阅服务的官方网站 —— 一个暗色霓虹风格的落地页，访客提交邮箱即可订阅每日早晚两次的 AI 资讯精选。

## ✨ 功能

- **暗色霓虹科技风落地页**：渐变流光标题、漂浮辉光球、发光网格、数据滚动计数、信源墙双向滚动
- **邮箱订阅**：访客提交邮箱即可订阅
- **响应式**：移动端 / 桌面端自适应

## 🏗️ 它背后是怎么运作的

```
65 个 AI 信源  ──▶  DeepSeek 智能精选去噪  ──▶  早 8:00 / 晚 21:00 邮件直达
（OpenAI、Anthropic、               （1400+ 条 → ~160 条）
  arXiv、量子位、卡兹克…）
```

- **抓取 + 精选**：基于开源项目 [TrendRadar](https://github.com/sansan0/TrendRadar)（多源抓取 + AI 筛选），按本项目需要做了信源与策略配置
- **本站**：负责介绍系统 + 收集订阅
- **推送**：定时把精选日报群发到订阅者邮箱

> 注：上游抓取引擎 TrendRadar 为第三方开源项目，遵循其自身开源协议，不包含在本仓库内。

## 🚀 本地运行

```bash
npm install
npm run dev      # http://localhost:3000
```

## 🛠️ 技术栈

Next.js 14 · TypeScript · Tailwind CSS · Framer Motion，部署于 Vercel。
